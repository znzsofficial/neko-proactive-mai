# Provenance and attribution

Neko Proactive Mai is an independent distribution maintained by NekoLaska.
It is not the official upstream project and this repository is not a GitHub fork.

The project is based on and substantially modified from:

- `clfr41/neko.proactive`
- https://github.com/clfr41/neko.proactive
- Upstream license: GNU Affero General Public License v3.0 or later

The current project changes the plugin identity to `neko.proactive`. Migration
preserves the existing scheduler settings, target allowlists, cooldown state,
Life outbox and receipt history. No runtime credentials, chat history or live
configuration is distributed.
